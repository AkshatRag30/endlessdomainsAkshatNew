How to add an account in MetaMask

  1. Open the MetaMask extension and click the account name at the top.
  2. Click Add account or hardware wallet, then Add a new account (choose Ethereum account if it asks for a type).
  3. Name it Trails buyer and create it. Repeat for Direct buyer.
  4. Nothing to back up: new accounts come from the same Secret Recovery Phrase you already have; each just has its own address.
  5. To copy an account's address, select it and click the address under its name. Send the addresses to whoever funds them.
  6. To use an account on the site, select it in MetaMask; if the site doesn't pick it up, open MetaMask's connected sites for localhost:3002 and connect that account too. If the site asks you to link or verify the new wallet (Profile, Wallets), do it: it's a signature, no gas.

Careful with the Trails buyer: funds must arrive on the Base network (not Ethereum or Polygon). Don't send it POL, and don't use it for anything else, so the "no POL needed" run stays valid.
