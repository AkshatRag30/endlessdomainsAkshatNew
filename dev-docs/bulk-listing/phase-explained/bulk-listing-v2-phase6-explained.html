Phase 6 in simple words: one approval per contract

1. The story in five sentences

  1. Listing is free, but the very first time, your wallet must let Seaport move your domain when it sells. That's one small transaction called an approval.
  2. The approval is per contract, not once for everything, so names from two different contracts need two approvals.
  3. Our old code only checked the first name's contract, showed a vague fee, and got confused when your wallet was on another network.
  4. Phase 6 checks each contract on its own blockchain, asks only for the missing approvals, and shows the real fee.
  5. Today you'll only see one contract; the rest is ready for multi chain.

2. What a "contract" is here

Every domain is an NFT that lives inside a contract, like a registry run by one provider on one blockchain. All Unstoppable Domains names on Polygon (.og, .unstoppable…) are in one contract. ENS names (.eth) on Ethereum are in another. When multi chain lets you list both, a batch with both kinds needs two approvals.

3. The bug it fixes

Before
Wallet on Ethereum, already approved: the button said "Approve, then list 2". The old check couldn't see Polygon from Ethereum, so it guessed "not approved".
Now
It asks Polygon directly, so the button says "List 2". The wrong network banner still asks you to switch before signing.

4. The steps, in order

#You seeWhat happens
1Open Bulk listNames are grouped by contract; each contract is asked "is Seaport approved?" on its own blockchain
2Click ListAll approved: straight to the one signature. Some missing: the approval screen
3"Approval needed · Unstoppable Domains · Polygon · ≈ 0.002 POL"Only missing contracts, with the real fee from the network
4"Approve in wallet" (or "Approve 2 in wallet")One transaction per contract; switches network first if needed
5The signature for all namesSame as phase 3

If you reject the second of two approvals, the first stays done and the screen shows only the one left.

7. Questions you might have

  1. Do I pay this every time I list?No. Once per contract per wallet. After that, listing is just a free signature.
  2. How much is the approval?On Polygon, a fraction of a cent in POL. The screen now shows the real number.
  3. Why build for many contracts if there's only one?Multi chain is part of the plan, and Mohit sir's F5 asks for it; it reuses this.
  4. How can I see the approval screen?Remove your approval on revoke.cash or Polygonscan (spender: Seaport), then bulk list.
