Phase 7 in simple words: the safety rules

Phase 7 is Mohit sir's F9: rules about which names can go into a bulk listing, so nobody buys a name that's about to lapse and one signature never mixes two blockchains. Written 24 Nov 2026; line numbers as of that day.

1. The story in five sentences

  1. Some domains expire. If someone buys one the day before it lapses, they've paid for a dying name.
  2. So a listing now always ends 7 days before the domain expires, and a name with under 14 days left can't be listed at all.
  3. One signature covers one blockchain, so a batch must be names from one chain, picked in the chain filter first.
  4. The real expiry date is read from the blockchain itself before signing, as Mohit sir's document says.
  5. And a link, ?bulk=1, lets the main website open bulk listing directly.

3. One chain per batch

A signature is tied to one blockchain, so Polygon and Ethereum names can't share one. Today only Polygon names can be listed, so entering select mode just sets the chain filter to Polygon (and leaving it puts your filter back). Once multi chain adds more chains, you'll be asked to pick a chain first: "Pick a chain in the chain filter to start selecting. One batch lists on one chain."

4. Expiry read from the blockchain

The page uses our database's date to grey out names quickly. When the drawer opens, and again when you press List, it asks the Unstoppable Domains contract for each name's real expiry (expiryOf; 0 means never expires). If the blockchain says a name has under 14 days left, the drawer says "Skipped: alpha.og expires within 14 days." and lists the rest. If the blockchain can't be reached, the database date is used.

5. The ?bulk=1 link

The main website is getting a "List several" button. It will open /seller-hub/my-domains?bulk=1, and My Domains then starts in select mode, ready to pick names. Test it by typing that address on 3002.

7. Questions you might have

  1. Why 7 and 14, not just 7?7 is how early a listing ends; 14 is the minimum life a name needs to be listed at all. Both are in decision 8.
  2. Will my names be affected?No: they never expire, so they list for the full duration.
  3. Why read the blockchain if we have the date?Mohit sir's document says to: the database date can be out of date, the contract's can't.
  4. Why are my .eth names hidden in select mode?The chain filter is on Polygon, the only chain you can list on today. They come back when you leave select mode.
