C. One chain per batch: pick the chain first (decision 2, C8) corrected after checking the PDF

The PDF: "A batch holds names from one chain only, so the chain filter must be set before selecting" and "Select mode requires a single chain filter; Select All and the banner count only names on that chain."

Today
Select mode works with the chain filter on "All Chain". Only Polygon names can be selected ("Only Polygon names can be listed for now"), so a batch is always one chain.
After
C1, one listable chain (today): entering select mode sets the chain filter to Polygon by itself, since it's the only chain you can list on. Leaving select mode puts your filter back.

C2, several listable chains (after multi chain): if the filter is on "All Chain", the banner says "Pick a chain in the chain filter to start selecting. One batch lists on one chain." and every Select is disabled until you pick one.
