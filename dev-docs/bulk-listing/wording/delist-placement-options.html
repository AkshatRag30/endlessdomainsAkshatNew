Delist button: 4 options

Today Delist is a small grey "Delist instead" link under "Sign new price" in the edit drawer, which is easy to miss. Each option below is drawn roughly as it would look. Pick one; the wording inside stays the approved wording.

Chosen 23 Nov: option 2, moved right under the "Lowering the price is free" note. Option 1 was ruled out because the Action column fits only one button on laptops.

Option 1 · Two buttons on the row my recommendation

Like most marketplaces ("Edit listing" and "Cancel listing" side by side). Your screenshot shows the Action column has room at this width; on a 13" laptop the two buttons get tighter (cards always have room). Delist leaves the edit drawer, so the drawer is only about the price.
