07

Static data, and the migration boundary

No src/data convention existed before this plan. Given the design system boundary already established this session, presentation only, data stays outside it, static fixtures live at a new src/data/marketplace/, five files, typed named exports only, no JSX.

The swap boundary is one hook per data need, never a prop change at the component level:

src/hooks/marketplace/useMarketplaceListings.tstoday → later
// today
export function useMarketplaceListings() {
  return mockListings
}

// later — same export shape
export function useMarketplaceListings() {
  const { data } = useGetAllDomainListingByQueryQuery(params)
  return useMemo(() => (data?.data ?? []).map(toMarketplaceListing), [data])
}

Components only ever receive MarketplaceListing[] / ActivityFeedItem[] / MarketMetric[] as props, never an RTK Query hook directly. When the backend changes, only the mapper and the hook's internals change, every composite and primitive is untouched.

12

Risks and open items

  • DomainResponse is declared twice in the codebase with different shapes, in Domain.ts and DomainList.ts, be careful which one gets imported later.
  • Three different debounce implementations exist in the repo; only useDebounces should be used here.
  • tokens.scss's own responsive value overrides (1400/1200/992/768/480) use a different breakpoint set than _mixins.scss's named mixins (500/768/992/1025/1440) — component layout standardizes on the named mixins.
  • No generic card‑shadow token exists yet; one additive token, --shadow-card, is proposed, no existing token changes.
  • Recharts here is 2.15.2, older than the main site's 3.x — confirm the typing workaround is actually needed rather than pre‑copying it.
  • The sidebar's collapse behavior has no ready‑made component to lift wholesale; expect to build it fresh, informed by DomainSearch's filter‑sidebar toggle.
  • Header is a fixed 59px bar with no sub‑nav slot — the new shell must sit as a sibling, not a child, and Layout's noHeader must stay true.
